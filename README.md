# 顔アプリ(口を開けて、歯を撮る)

口を開けて、歯が見えるように、撮影を手伝う、Web アプリです。
カメラの映像から、顔と口の位置を見つけて、「もう少し近づいてください」「口を大きく開けてください」などの案内を出します。条件がそろって、約1秒続くと、1枚、撮ります。

## 大事な注意

- これは、撮影の**ガイド**です。**医療の判定では、ありません**。
- 歯の判定は、画素の明るさと色で見る、簡易な方法です。照明、カメラ、歯の色によって、**誤ることがあります**。
- 判定の境目の数字は、作者の環境で決めた物です。ほかの環境では、合わないことがあります。

## 映像と写真の扱い

- 映像と写真は、使う人の端末の中だけで処理します。**サーバーには、送りません**。
- 写真は、「撮れたら自動で保存する」にチェックを入れた時だけ、端末に、ダウンロードされます(標準は、保存しません)。
- このページを置いているサービスには、ページを開いた記録(アクセス記録)が、残ることがあります。映像と写真は、含まれません。

## 使い方

1. 伝えられた URL を、ブラウザで開く
2. カメラの使用を、許可する
3. 画面の案内に従って、距離、向き、口の開きを、整える(口を開けて、唇を引いて、歯を見せる)
4. 全部の項目に ✓ が付いて、約1秒続くと、静止画が出る

- 「もう一度撮る」で、撮り直せます。
- スマホでは、ブラウザのメニューから、ホーム画面に追加できます。
- 新しくならない時は、アプリを**完全に終了して**、開き直してください。

## 確かめた環境

- Windows の Edge で、本物のカメラを使って、確かめました。
- iPhone の Chrome で、本物のカメラ(前面カメラ)を使って、確かめました(画面の並び、案内、撮影、ホーム画面への追加)。
- Android、iPhone の Safari、ほかの機種やブラウザでは、確かめていません。

## 自分の PC で動かす

Python が入っている PC では、`run.bat` をダブルクリックすると、ローカルのサーバーが起動して、ブラウザが開きます(`http://localhost:8782`)。
`index.html` を、ダブルクリックで、直接開いても、動きません(ブラウザの安全の決まりのため)。
